# Phase 6 – Project Testing

## Test cases

| Test | Input | Expected result |
|---|---|---|
| 1 | General fitness + beginner | 7-day routine is generated |
| 2 | Strength & mobility | Routine reflects mobility/strength focus |
| 3 | 10 minutes/day | Short routine is generated |
| 4 | Preferences entered | Output considers preferences |
| 5 | No API key | Clear configuration error |
| 6 | API failure | Clear error message is shown |

## Acceptance criteria
- App launches successfully.
- User can submit inputs.
- Gemini response is displayed.
- API key is not exposed in the repository.
- Output contains a safety note.
