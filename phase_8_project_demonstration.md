# Phase 8 – Project Demonstration

## Demo video script

### 1. Project name
"Hello, this is our project FitBuddy – AI Fitness Plan Generator Using Gemini Models."

### 2. Purpose
"The purpose is to demonstrate how Generative AI can create a simple personalized wellbeing routine from user preferences."

### 3. Benefits
"It provides a simple interface and demonstrates prompt engineering and Gemini integration."

### 4. Working process
"First, the user selects a goal, experience level and available time. The application converts these inputs into a structured prompt. The prompt is sent to Gemini, and the generated routine is displayed in the application."

### 5. Final output
Show the generated 7-day routine on screen.

### 6. Closing
"This project demonstrates a complete Generative AI workflow from user input to AI-generated output."
