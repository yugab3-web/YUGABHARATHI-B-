# Phase 2 – Requirement Analysis

## Functional requirements
1. User can enter/select basic preferences.
2. System validates the input.
3. System constructs a prompt.
4. Gemini generates the routine.
5. System displays the generated routine.
6. Errors are shown clearly.

## Non-functional requirements
- Simple interface
- Fast response when the API is available
- Readable output
- API key must remain private
- Basic safety instructions included

## Hardware
- Computer/laptop
- Internet connection

## Software
- Python 3.10+
- Streamlit
- Google Gemini API
- Web browser
- GitHub
