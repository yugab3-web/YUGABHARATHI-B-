# Phase 7 – Project Documentation

## Project title
FitBuddy – AI Fitness Plan Generator Using Gemini Models

## Purpose
Demonstrate how Generative AI and prompt engineering can be used to generate a personalized text-based wellbeing routine.

## Benefits
- Simple interface
- Personalized output
- Demonstrates GenAI integration
- Useful as a learning project
- Easy to extend

## Technologies
Python, Streamlit, Gemini API, Prompt Engineering.

## Limitations
- Requires an internet connection and Gemini API access.
- Generated content may need human review.
- It is not medical advice.
